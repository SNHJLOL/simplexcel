# Simplexcel

一个把 [simple.imsummer.cn](https://simple.imsummer.cn/web) 的帖子数据变成「Excel 风格」本地表格的小工具：广场 / 关注 / 我的三张工作表，支持手动刷新、滚动懒加载、排序、筛选、列显隐、评论区、点赞 / 收藏和 CSV 导出，全部在你自己的浏览器里操作，数据用你自己的账号读取。

## 功能特性

- **仿真 Excel 界面**：标题栏、功能区、公式栏、表格、状态栏，操作习惯接近 WPS / Excel。
- **广场数据**：表格展示广场帖子，含图片 / 视频缩略图，点击可查看大图。
- **多工作表**：状态栏页签可在「广场」「关注」「我的」之间切换，分别对应广场帖、关注用户的帖子、自己发布的帖子；点表格里的头像还会新开一张该用户的主页工作表（可关闭）。
- **懒加载**：滚动到底部自动加载更多，也可点击底部按钮手动加载。
- **点赞 / 收藏**：表格内以复选框形式一键点赞、收藏（再次点击取消）；「原帖详情」里也有一组点赞 / 收藏按钮，状态与表格联动。
- **评论区**：点击任意行弹出该帖子的评论，可直接发表评论或回复；评论与回复都支持点赞（👍），再次点击取消。
- **点赞和回复**：右上角「点赞和回复」列出谁赞了 / 评论了你；点「查看原帖」会展示原帖的完整正文与图片 / 视频，并可继续查看 / 发表评论、点赞 / 收藏。
- **排序**：点击列头按该列排序，再次点击切换升 / 降序。
- **搜索**：右上角按昵称 / 内容 / ID 过滤当前已加载的数据。搜索期间会暂停「滚动到底部自动加载」，避免一边搜一边疯狂翻页（仍可点底部按钮手动加载）。
- **列显隐与列宽**：勾选要显示的列；拖拽列头右边的手柄可像 Excel 一样调整列宽，选择与宽度都会记住。
- **复制**：双击单元格复制内容；「复制」按钮可复制整行。
- **键盘导航**：像 Excel 一样用方向键在单元格间移动，Home / End 跳列首列尾，PageUp / PageDown 翻页。
- **评论媒体**：评论区里评论 / 回复自带的图片、视频、语音以缩略图展示，点击可看大图 / 播放。
- **导出 CSV**：把当前筛选结果导出成 Excel 可直接打开的 CSV 文件。
- **页面缩放**：状态栏 + / − 按钮或 Ctrl + 滚轮调整整个页面大小（缩放比例会记住）。
- **换行**：一键切换「内容」列是否自动换行（选择会记住）。
- **对齐**：左对齐 / 居中 / 右对齐，**作用于当前选中的列**（没选中任何单元格时作用于所有列），按列分别记住。表头会跟着一起对齐。
- **批量删除**：「我的」工作表专有。点功能区最右边的「删除」进入删除模式，表格会多出一列勾选框，勾好要删的动态后点「确认删除」，**再二次确认**一次才会真正删掉（删除不可恢复）。

## 环境要求

- 电脑能联网，能访问 simple.imsummer.cn。
- 方式一（推荐，无需安装）：使用打包好的 `Simplexcel.exe`（见下文「打包成 EXE」）。
- 方式二：安装 [Node.js](https://nodejs.org/) 18 或更高版本（LTS 即可）。

## 快速开始

1. **准备登录 Token**（只需一次，约 30 天有效）：
   
   - 先用 Edge 浏览器登录 [simple.imsummer.cn/web](https://simple.imsummer.cn/web)。
   - 按 `F12` 打开开发者工具 → 切到「控制台」标签 → 粘贴下面这行代码后回车：
   
     ```js
     JSON.parse(JSON.parse(localStorage.getItem('flutter.UserInfo'))).token
     ```
   
   - 代码运行后 Token 已自动复制到剪贴板（若提示 `undefined`，见文末「常见问题」）。
   
2. **填入 Token**：
   
   - 先启动程序，再在网页右上角点「登录」，把 Token 粘贴进对话框，点「登录」，会自动保存。

3. **启动**：
   - 在本项目目录打开终端（PowerShell），执行：
   - 无需先安装任何依赖：`server.js` 只用到了 Node.js 自带模块（零依赖），装好 Node.js 后直接运行即可。

     ```powershell
     npm start
     ```

     或直接：

     ```powershell
     node server.js
     ```

4. **打开页面**：浏览器访问 <http://localhost:3000>。
   - 若 3000 端口被占用，程序会自动尝试 3001、3002…，以终端里显示的地址为准。
   - 看到表格里的「广场」数据即表示成功。

> 提示：首次加载源站数据可能较慢（有时需要 20 秒左右），页面会显示加载状态，属正常现象。

## 界面与操作说明

### 标题栏
- 「文件」菜单：手动刷新、导出 CSV、显示列、关于。
- 右上角「登录 / 退出登录」：管理当前账号；登录弹窗里也能直接粘贴新 Token 切换账号。

### 功能区（表格上方）
- **复制**：复制当前选中行（Tab 分隔，可直接粘进表格软件）。
- **刷新**：重新拉取第一页数据（会绕过缓存，获取最新内容）。
- **导出CSV**：导出当前筛选 / 排序后的结果为 CSV。
- **换行**：切换「内容」列自动换行，长文本默认换行。
- **左对齐 / 居中 / 右对齐**：设置列内容对齐方式。作用范围是**当前选中的列**（先点一下该列的任意单元格再点按钮），若从未选中过单元格则作用于所有列；toast 会告诉你这次改了哪几列。数值列默认右对齐、头像 / 点赞 / 收藏默认居中，其余默认左对齐，设置会按列记住。
- **列显示**：勾选要显示的列，取消勾选即隐藏。
- **搜索框**：输入关键词实时过滤，支持昵称、内容、ID。
- **删除 / 确认删除 / 取消**（功能区最右边）：批量删除「我的」动态，详见下面「表格区 → 批量删除」。只有切到「我的」工作表时按钮才可点，其它工作表里是置灰的（鼠标悬停有说明）。

### 表格区
- **排序**：点击列头排序，再次点击切换升 / 降序。注意排序只针对**已经加载到本地的行**。「点赞」「收藏」列按状态（已赞 / 未赞、已收藏 / 未收藏）排序。
- **列宽**：拖拽列头右边缘的手柄调整宽度，内容过长自动换行；宽度会记住。
- **列对齐**：功能区「对齐」组的三个按钮，作用于当前选中的列（详见「功能区」一节）。
- **点赞 / 收藏**：点击「点赞」「收藏」列里的复选框即可操作，状态即时反馈。
- **图片 / 视频**：点击缩略图打开大图，滚轮缩放、按住拖动、双击重置，也可「在新窗口打开」。视频 / 实况照片打开后会**自动播放**（实况照片循环播放，普通视频播完即停）；同一格 / 同一条评论里的多个媒体可用左右方向键或两侧箭头翻页，翻页或关闭时会自动停掉上一段，不会出现两段声音重叠。源站的实况 / 视频多为 H.265(HEVC) 编码，浏览器缺解码器时会「有声音、画面不动」，此时**不弹提示、直接在本机转成 H.264 播放**（详见「常见问题」）。
- **行详情 / 评论**：点击「评论数」单元格打开该帖子的评论区，可发送评论（Enter 发送，Shift+Enter 换行）；若是对评论的回复，输入框会带回复目标。评论 / 回复里带的图片、视频、语音会显示缩略图，点击即可查看或播放；点头像则跳到该用户的主页（并关闭评论区）。
- **原帖详情（从「点赞和回复」点「查看原帖」进入）**：上方展示原帖的正文与图片 / 视频 / 实况照片缩略图（通知里带过来的原帖信息会先顶上，随后用单帖接口补齐），点缩略图同样打开灯箱；正文下方有一组**点赞 / 收藏**按钮，状态取自这条帖子，点一下即可切换，并且会同步到表格里的同一条帖子。「‹ 返回」回到通知列表。
- **复制单元格**：双击某个单元格，内容即复制到剪贴板。
- **用户主页**：点击表格里的头像，会在状态栏新开一张以该用户昵称命名的工作表，展示他 / 她发布的帖子（和其它工作表一样支持滚动加载更多）；点页签上的「×」可关闭（内置的广场 / 关注 / 我的不能关闭）。点自己的头像则直接切到「我的」。**「点赞和回复」弹窗、评论区和原帖详情里的头像同样可点**，点击后会关掉当前弹窗再跳到该用户的主页。
- **键盘导航**：点击任意单元格后，用方向键上下左右移动（详见下方快捷键表）。
- **批量删除（仅「我的」工作表）**：点功能区最右边的「删除」进入删除模式 → 表格行号右侧多出一列勾选框（表头的复选框可一键全选当前显示的行）→ 勾选要删的动态（被勾选的行会标红）→ 点「确认删除」，会弹出二次确认框并列出即将删掉的内容 → 点「确认删除 N 条」才真正执行。删除成功后这些行会立刻从表格里消失并自动退出删除模式。
  - 删除是逐条调用上游的 `DELETE /api/v3/posts/{id}`，不可恢复，请确认无误再点最后那一下。
  - 中途想退出：点「取消」按钮（或再点一次「删除」），会清空勾选并退出删除模式。
  - 若某条删除失败（例如上游限流返回「操作过快」），会自动隔一会儿重试一次；仍失败的会保留勾选并在顶部给出原因，可直接再点一次「确认删除」重试，已删掉的不会重复处理。

### 状态栏
- 左侧显示当前工作表、行数、上次刷新时间；页签由脚本渲染，点页签切换、点用户页签上的「×」关闭。
- 右侧 + / − 按钮缩放页面；页签后的「＋」是界面仿真按钮，点击会提示正确的新增方式（点表格里的头像）。

## 数据来源

三张内置工作表 + 动态打开的用户主页，对应上游的不同接口，切页签时自动重新拉取：

| 工作表 | 上游接口 | 说明 |
|---|---|---|
| 广场 | `/api/v2/posts` | 广场公开帖子，支持 `last_id` 翻页 |
| 关注 | `/api/v3/posts/followings` | 关注用户的帖子（带 `user_scope=normal`） |
| 我的 | `/api/v3/posts/mine` | 自己发布的帖子 |
| 用户主页 | `/api/v3/posts/profile` | 某个用户发布的帖子，点表格头像打开 |

- 「我的」所需的 `user_id` 由本地服务自动获取当前登录用户后补上，前端不需要知道自己的 id；也可手动带上 `user_id` 覆盖。
- 「用户主页」必须显式带 `user_id`。该接口同样用 `last_id` 游标翻页，但 `per_page` 上限只有 30（再大直接报 400），本地服务会把它收敛到 30 以内，所以这张工作表也能像其它表一样滚动加载更多。

除了读取，本地服务还代理了一个写操作：

| 操作 | 上游接口 | 说明 |
|---|---|---|
| 批量删除 | `DELETE /api/v3/posts/{id}` | 「我的」工作表的批量删除逐条调用；成功后本地会丢弃该列表的缓存，避免刷新还能看到已删的帖子 |

另外还有一个**不走上游**的本地能力：

| 操作 | 说明 |
|---|---|
| `POST /api/open-media` | 把灯箱里播放不了的实况 / 视频交给本机播放器（详见「常见问题」里的 HEVC 一节）。地址同样受媒体白名单约束，只接受 POST，避免被预取或误触发。 |
| `GET /api/transcoded?url=…` | 把该媒体转码成 H.264 后直出（带 Range 支持，能拖进度条）。`check=1` 时只回报进度并在后台预热，不阻塞。地址同样受媒体白名单约束。 |
| `GET /api/ffmpeg/status` | 本机有没有 ffmpeg、装在哪个路径、以及自动安装的下载进度。 |
| `POST /api/ffmpeg/install` | 一键下载安装 ffmpeg 到 `%LOCALAPPDATA%\Simplexcel\ffmpeg`（仅 Windows；不写系统目录、不需要管理员）。下载在后台跑，前端轮询上面的 status 看进度。 |

## 可选配置

以下均为可选，默认即可正常使用：

| 配置 | 说明 | 默认 |
|---|---|---|
| 环境变量 `PORT` | 修改监听端口 | `3000` |
| 环境变量 `SIMPLE_HOST` / `config.json` 的 `host` | 监听地址。默认只允许本机访问；设为 `0.0.0.0` 才会对局域网开放 | `127.0.0.1` |
| 环境变量 `SIMPLE_TOKEN` | 用环境变量提供 Token（优先级高于 `config.json`） | 无 |
| `config.json` 的 `token` 字段 | 本地保存的登录 Token | 无 |
| 环境变量 `SIMPLE_PLAYER` | 指定用哪个播放器打开实况 / 视频（填可执行文件的完整路径） | 自动探测 PotPlayer → VLC → mpv |
| 环境变量 `SIMPLE_MEDIA_HOSTS` / `config.json` 的 `mediaHosts` | 允许代理的媒体域名后缀（逗号分隔）。默认 `imsummer.cn`，即该域名下所有子域都放行 | `imsummer.cn` |
| 环境变量 `POST_CACHE_TTL` / `COMMENT_CACHE_TTL` / `FAV_CACHE_TTL` / `NOTIFY_CACHE_TTL` / `ME_CACHE_TTL` | 各类接口结果缓存时长（毫秒） | 120000 / 15000 / 15000 / 15000 / 300000 |
| 环境变量 `CACHE_MAX_ENTRIES` | 每个缓存最多保留的条目数，超出后淘汰最早插入的一条 | `300` |
| 环境变量 `SIMPLE_FFMPEG` / `config.json` 的 `ffmpegPath` | 指定 ffmpeg 可执行文件的完整路径（不想用自动下载的那份时用） | 自动探测：该路径 → 用户目录 → PATH |
| 环境变量 `SIMPLE_H264_CACHE_MAX` | 转码缓存最多保留多少个文件，超出按修改时间淘汰最旧的 | `200` |
| 环境变量 `SIMPLE_TRANSCODE_TIMEOUT` | 单个视频的转码超时（毫秒） | `600000`（10 分钟） |
| 环境变量 `SIMPLE_NO_OPEN` | 设为 `1` 时，打包版启动后不自动打开浏览器 | 无 |

示例：指定端口启动

```powershell
$env:PORT = 8080
node server.js
```

示例：需要让同局域网的手机也能打开（**会暴露你的 Token，请确认网络环境可信**）

```powershell
$env:SIMPLE_HOST = "0.0.0.0"
node server.js
```

## 打包成 EXE（可选）

不需要 Node.js 环境的同学可以直接用打包好的 exe：

1. **双击仓库根目录的 `打包.cmd`** 就行：它会自己检查 Node.js、缺 `pkg` 就顺手装依赖、打包、再把产物信息打在窗口里。等价的手工命令是：

   ```powershell
   npm install        # 只有第一次需要
   npm run build:exe
   ```

   打包前记得先退出正在运行的 `Simplexcel.exe`（Windows 不允许覆盖正在运行的程序），脚本检测到也会问你要不要帮它结束。热缓存下打包约 3 秒。

2. 打包产物在 `dist/Simplexcel.exe`。把 `Simplexcel.exe` 和 `config.json`（含你的 Token）放在**同一目录**，双击 exe 即可运行，程序会自动打开浏览器页面。
3. 不想自动打开浏览器时，先设置环境变量 `SIMPLE_NO_OPEN=1` 再运行。

## 自测（可选）

- `test/ui.test.js`：用 [jsdom](https://github.com/jsdom/jsdom) 加载真实的 `index.html` + `app.js`，驱动真实交互断言——评论区媒体渲染、点赞 / 收藏列排序、排序 / 搜索后选区跟随同一条帖子、搜索时暂停自动加载、方向键导航、错误提示转义、视图偏好持久化、列对齐（左 / 中 / 右）、工作表页签切换、点头像打开 / 关闭用户主页工作表及其翻页、评论区与「点赞和回复」里的头像跳转、批量删除（按钮可用范围、删除列、全选 / 勾选、二次确认的取消与 Esc、逐条 DELETE、删完自动退出删除模式）、视频 / 实况照片打开即播放（调用 `play()`、实况循环、被拦下自动静音重试、翻页与关闭时暂停上一段、加载失败给出可读提示）、HEVC 缺解码器时的识别与静默转码（能解出画面时不误报、解不出时不弹提示条也不弹按钮、自动开始轮询并在就绪后把 `<video>` 切到 `/api/transcoded`、转码地址取不到时静默退回原文件）、本机转码兜底（没 ffmpeg 时自动 POST `/api/ffmpeg/install` 且安装期间不重复发、装好后自动接着转码、装不上就安静收手不再重试）、「查看原帖」的原帖详情（用通知里的 `to_media` 兜底渲染媒体、缩略图可点开并播放、点赞 / 收藏按钮与表格联动）。
- `test/server.test.js`：把 `https` 层替换成桩，不联网也能验证服务端行为——`/media` 白名单与报错文案、`per_page` 上限收敛、默认只监听本机、工作表数据源路由（广场 / 关注 / 我的 / 用户主页）、删帖代理（`DELETE /api/posts/:id` 只转发 DELETE、成功后清列表缓存、上游 404 的 i18n 占位换成中文）、`/api/open-media` 的白名单校验与「只收 POST」、转码接口（白名单与 http 拒绝、只接受 GET、没有 ffmpeg 时给 412 中文提示且不打上游、`check=1` 只回报进度）、`/api/ffmpeg/status` 与 `/api/ffmpeg/install`（只接受 POST、未知子操作 404）、静态资源与路径穿越防护。

## 常见问题

- **控制台执行获取 Token 的代码返回 `undefined`**：说明当前网站的存储 key 不是 `flutter.UserInfo`（网站可能更新）。在控制台执行 `Object.keys(localStorage)` 找出保存登录信息的 key，再用 `JSON.parse(JSON.parse(localStorage.getItem('key名')).token)` 提取。
- **页面提示「登录已失效」**：Token 过期（约 30 天有效），按「快速开始」重新获取并更新 Token 即可。
- **端口被占用**：程序会自动向后尝试 3001、3002…，以终端打印的地址为准；也可用 `PORT` 环境变量指定端口。
- **数据加载很慢**：源站响应偶尔较慢，首包可能要等 20 秒左右；可以点「刷新」重试。
- **图片 / 视频不显示**：多为网络原因，稍后点「刷新」重试即可。若源站换了 CDN 域名，会提示「媒体地址不合法」，此时用 `SIMPLE_MEDIA_HOSTS`（或 `config.json` 的 `mediaHosts`）把新域名后缀加进白名单即可。
- **视频 / 实况照片打开后不动**：浏览器会拦截「带声音的自动播放」，只靠 `<video autoplay>` 往往停在首帧。本工具在点击缩略图的那一刻就调用播放，被拦下时会自动改用**静音播放**；若仍被拦（例如把页面嵌在 iframe 预览里），画面正中会出现一个圆形播放按钮，点一下即可带声音播放。若灯箱底部提示「媒体加载失败（错误码 …）」，那是文件本身没取到（CDN 拒绝、网络中断），可点「在新窗口打开」直接访问原文件确认。
- **只有声音、画面停在一张图上（HEVC）**：这是最常见的一种。源站的实况照片 / 视频基本都用 **H.265 / HEVC** 编码，而 Windows 默认不装 HEVC 解码器（实测 59 个抽样文件里 52 个是 HEVC），于是浏览器会跳过视频轨、只播音频——**声音正常，画面永远停在封面图上**。现在遇到这种情况**不会弹任何提示**：本工具识别出「已经在播却拿不到画面尺寸」后，直接在本机把视频轨转成 H.264 播放：
  - 全程自动：先把原文件播着（此时有声音），后台转码，转好自动切换画面，**不用点任何按钮**；转好的文件按源地址缓存，同一条第二次打开是本地直读，秒开。
  - 确认过一次「这台机器解不了 HEVC」之后，后面的实况 / 视频会直接吃转码版，不再出现「先只有声音」那一下。
  - 机器上没有 ffmpeg 时会自动下载一份（详见下一条），装完立刻接着转；装不上就安静放弃，回到原来「有声音没画面」的状态，不会反复重试。
  - 如果你已经装了「HEVC 视频扩展」、浏览器能硬解，就完全不会触发上面这些，直接播。
  - 想用本机播放器（PotPlayer / VLC / mpv，都自带 HEVC 解码）看原文件的话，服务端仍保留 `POST /api/open-media` 这个接口（地址受同样的白名单约束）。
- **ffmpeg 从哪来**：机器上本来就有（PATH 里、或 `SIMPLE_FFMPEG` / `config.json` 的 `ffmpegPath` 指定）就直接用；没有的话，第一次遇到解不出画面的实况 / 视频时**自动下载**一份预编译的 ffmpeg 解压到 `%LOCALAPPDATA%\Simplexcel\ffmpeg`——**不写系统目录、不需要管理员权限**，也没有确认弹窗。下载源按实测速度依次尝试：npm 镜像（约 21MB，国内十几 MB/s，几秒完成）→ npm 官方 → gyan.dev 官方构建 → GitHub BtbN 构建。装好后无需重启，会自动接着转码。macOS / Linux 不会自动下载，请用 `brew install ffmpeg` / `apt install ffmpeg` 自行安装；不想让它自动下载可以设置 `SIMPLE_NO_FFMPEG_INSTALL=1`（此时只使用本机已有的 ffmpeg）。
- **前端改动看不到效果**：`public/` 是每次从磁盘读的，改完直接**硬刷新**（Ctrl + F5）即可；但如果用的是打包版 `dist/Simplexcel.exe`，它内嵌了前端资源，必须先 `npm run build:exe` 重新打包。
- **想让手机在同一 Wi-Fi 下打开**：默认只监听 `127.0.0.1`，需要显式设置 `SIMPLE_HOST=0.0.0.0`；注意这等于把带 Token 的代理开放给整个局域网。

## 安全与注意事项

- Token 等于你的账号登录态，**不要**把它贴到公开场合或分享给他人；`config.json` 已加入 `.gitignore`，请勿提交到仓库。
- 服务端默认**只监听本机**（`127.0.0.1`），同局域网的其他人无法打开这个工具、也无法借用你的 Token；只有你显式设置 `SIMPLE_HOST=0.0.0.0` 才会对外开放。
- `/media` 只代理白名单域名下的 https 资源，避免被当作任意地址的转发跳板。
- **自动下载 ffmpeg 会拉可执行文件**：只在第一次遇到「解不出画面」的实况 / 视频时触发，且只写到 `%LOCALAPPDATA%\Simplexcel\ffmpeg`（不写系统目录、不需要管理员）。下载源固定为上面列出的几个（npm 镜像 / gyan.dev / GitHub 官方 Release），不会从任意地址拉二进制；装好后可以在那个目录里直接删掉，不影响其它功能。不想让它下载就设置 `SIMPLE_NO_FFMPEG_INSTALL=1`。
- `/api/transcoded` 与 `/api/open-media` 一样只接受白名单内的 https 地址，转码缓存放在 `%TEMP%\simplexcel-media\h264`，最多保留 200 个文件（超出按时间淘汰）。
- **删除不可恢复**：批量删除只作用于「我的」工作表（自己的动态），并且会二次确认；请看清确认框里列出的内容再点最后那一下。
- 这是个人使用的工具：用自己的账号看自己的数据，请勿高频抓取或公开分发数据。
